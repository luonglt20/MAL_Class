03 · Attention là gì

Attention: mô hình tự quyết định nên chú ý vào đâu

Cách hoạt động

Mỗi token hỏi các token khác: ai liên quan tới mình? Token càng liên quan càng được chú ý nhiều, token không liên quan gần như bị bỏ qua.

Ví dụ đối chiếu chéo

Hàm import tải file từ mạng (góc tĩnh) được nối với sự kiện ghi file rồi chạy file đó (góc hành vi).

Từng dấu hiệu riêng lẻ thì yếu; ghép lại mới thành bằng chứng mạnh.

TAKA10 · Lê Tuấn Lương · 8 · Ví dụ mang tính minh họa · Attention [7], Graph attention [8]

Attention có thể hiểu đơn giản là mô hình tự quyết định nên chú ý vào đâu. Mỗi token hỏi các token khác xem ai liên quan tới mình; token càng liên quan càng được chú ý nhiều. Khi làm việc này giữa hai góc khác nhau thì gọi là cross-attention. Ví dụ minh họa: một hàm import dùng để tải file từ mạng, nhìn riêng thì chưa chắc độc hại. Nhưng khi nối với sự kiện ghi file rồi chạy chính file đó trong hành vi, hai dấu hiệu yếu ghép lại thành bằng chứng mạnh.
