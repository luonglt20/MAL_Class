TAKA10 · Lê Tuấn Lương · 13 · EMBER2024 [6]

Phần ứng dụng là một dashboard chạy cục bộ. Dashboard tự chọn mô hình theo đầu vào: report có hành vi thì dùng mô hình ba góc train trên WinMET; chỉ có file PE thì dùng mô hình tĩnh train trên EMBER2024. Có ba lớp an toàn: file PE được đọc trong sandbox của macOS, cấm mạng, ghi file và tạo process; nếu đầu vào có quá ít token quen thuộc thì trả UNKNOWN; và checkpoint được khóa bằng SHA-256, dữ liệu sai phiên bản chuẩn hóa sẽ bị từ chối.
